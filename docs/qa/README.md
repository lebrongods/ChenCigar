## 这是历史报告，不代表当前版本

报告记录的是 **v2.1.0 基线**。当前 `main` 已更新到 **v2.4.2**，功能和代码结构均有较大变化，项目自带自动化测试为 68/68 通过。请勿把报告中的问题直接当作当前版本的缺陷列表。

| 报告编号 | v2.1.0 基线问题 | 当前 v2.4.2 状态 |
|---|---|---|
| BUG-01 | 改派后原承办人仍可继续补拍 | 已修复；写入前重新核对权限，见 `tests/accounts.test.js` |
| BUG-02 | “件”无法折算导致打包金额为 0 | 已修复；“件”按 50 条折算，未核价/无法折算物品打包前要求确认 |
| BUG-03 | 改品规后仍沿用旧价格/条码来源 | 已修复；目录外品名改为手工价，见 `tests/bugfix.test.js` |
| BUG-04 | 价格目录更新后核价表引用新版本、单价来自旧版本 | 建议复核；`priceBasisText` 仍按当前目录生成依据，未在现有 68 条测试中看到对应回归 |
| BUG-05 | 相册导入被记成当前拍摄时间/位置 | 已修复；相册记录改为“导入时间”，不再记录当前位置 |
| BUG-06 | 打包校验错误卡不随补拍失效 | 建议复核；当前源码仍未见数据变更时统一清除 `packResult` |
| BUG-07 | 删除失败仍提示成功、索引写失败仍提示创建成功 | 建议复核；删除返回值仍被忽略，索引写入失败仍未计入 `saveCase` 的返回值 |
| BUG-08 | PIN 锁定刷新可绕过 | 已修复；锁定状态保存在本机，刷新后仍锁定 |
| BUG-09 | 合并重复品规时丢失第二次价格 | 已修复；单价不同不提示合并，见 `tests/bugfix.test.js` |
| BUG-10 | 本地条码库品名无法反查 | 建议复核；`lookupName` 仍只查价格目录，但品名候选仍包含本地条码库 |
| BUG-11 | 临时编号同分钟重复 | 建议复核；生成规则仍只精确到分钟 |
| BUG-12 | 案件页返回后浏览器后退又回到案件 | 建议复核；应用内返回仍使用 `go(..., false)` 追加历史记录 |

“建议复核”表示本次只做了当前源码静态对照，**没有在 v2.4.2 上重新完整复现**；在正式关闭这些问题前，应按报告中的复现步骤重新跑一遍，或补成自动化回归。
