# 涉烟案件现场证据采集系统 · 使用说明（稽查人员版）

> 系统就是一个网页文件（`证据采集系统.html`），用手机浏览器打开即可，不用安装。建议用手机自带浏览器或 Chrome / Safari 打开；**微信里打开可能下载不了证据包**，请点右上角"…"→"在浏览器打开"。

## 现场取证 6 步

**第一步　登录**
选自己的名字，输入 4–6 位数字 PIN。连续输错 5 次要等 30 秒。忘了 PIN 请找管理员重置。

**第二步　新建案件**
点"＋ 新建案件"→ 填案件编号（没有正式编号可先点"临时编号"，以后在"编辑信息"里改）→ 选案件类型（无证运输 / 无证经营 / 假烟销售 / 制假窝点）→ 现场地址、当事人可填可不填 →"创建并开始取证"。
新建的案件暂时没有承办人，由管理员之后分配。

**第三步　按清单逐项拍照**
页面按类别列出要拍的项目，红框、标"必拍"的必须拍，标"选拍"的看情况拍。
- 点"拍照"直接调相机；聊天记录、转账记录这类截图点"相册"选图。
- 拍完如果提示"建议重拍：画面偏暗 / 过曝 / 可能模糊"，照片已经保存了，只是提醒你看一下，需要的话点"重拍"。
- 点缩略图可看大图、拍摄时间、位置；拍错了可"重拍""相册替换"或"删除"。重拍时会先让你对比新旧两张，选"保留原照片"就不会换掉。
- 清单外还想补的照片，拍在最下面"补充照片"里，并写一句说明。

**第四步　登记查获卷烟**
在"查获卷烟"下点"＋ 登记"：
1. 点"扫码"对准卷烟条码拍一张，能识别就自动填条码，这张照片也会作为该品规的照片；识别不了（例如 iPhone 一般不支持）就在"条码"框手工输入。
2. 填**品规**和**数量**（单位可选 条 / 包 / 支 / 件），两项都必须填，数量要大于 0。
3. 同一个条码第二次出现时，系统会自动带出上次填的品规，核对一下即可。
4. 条码框提示"校验位不符"，说明很可能输错了一位，请核对。

**第五步　校验并生成证据包**
点底部"校验并生成证据包"：
- 有必拍项没拍、没登记查获卷烟、或品规/数量没填，系统会**列出缺什么并拒绝打包**，点缺项可直接跳过去补。
- 都齐了就会下载一个 ZIP 文件，名字是"案件编号\_证据包\_日期时间.zip"。手机支持的话还可以点"发送/分享"直接发给承办人。

**第六步　移交**
把 ZIP 交给承办人。ZIP 里有：
- 按"案件编号\_类别\_项目.jpg"命名好的照片；
- `证据清单说明.txt`：案件信息、每张照片的拍摄时间、位置、SHA-256 摘要、查获卷烟明细、操作日志；
- `SHA256SUMS.txt`：承办人在电脑上可用它核对照片在打包后有没有被改动（方法写在清单说明第五部分）。

## 需要知道的限制
1. 账号权限只是界面上的控制，不是服务器级的安全保护，请不要把系统链接和数据发给无关人员。
2. 别人新建或修改的案件要刷新才能看到（列表页每 30 秒自动刷新，也可点"刷新"）；**两个人不要同时改同一个案件**。
3. 系统只能保证必拍项**不会漏拍**，不能保证**拍得对、拍得清**，照片内容仍需自己把关。
4. 备份要靠管理员定期在"管理 → 数据备份与还原"里手动导出，不是自动备份。
5. 如果页面顶部出现红色"保存失败"，说明刚才的修改没存进去：先别关页面，检查手机存储空间后重新操作，并告诉管理员。

## 附：如何实测"单案证据采集与归档耗时"（供 QC 报告第六章使用）

**指标定义**：从到达现场开始取证，到证据按规定命名归档、可以移交承办人为止的总时长（分钟/案）。

1. **改进前**：从历史记录中整理同类型案件 **不少于 20 起**的耗时；如果是凭回忆估算的，每条都要注明"估算"。
2. **使用系统后**：同类型案件 **不少于 20 起**，用手机秒表计时。
3. **分段计时**（每起案件记 4 个数）：
   - ① 拍照：开始拍第一张 → 必拍项全部拍完；
   - ② 登记查获：开始登记 → 查获卷烟全部登记完；
   - ③ 整理命名：（改进前）整理、改名、归档照片的时间；（使用系统后）点"生成证据包"到下载完成；
   - ④ 移交：把证据交到承办人手上（或发出）所用时间。
4. **统计时同时给出中位数和平均值**，并写明样本量（例如"n=23"）。
5. 效率提升计算公式：ΔS = (M1 / M2 − 1) × 100%，M1 = 改进前，M2 = 改进后。

建议记录表格列：序号｜案件类型｜日期｜①拍照｜②登记查获｜③整理命名｜④移交｜合计｜是否估算｜备注。
