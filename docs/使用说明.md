# 涉烟案件现场证据采集系统 · 使用说明（稽查人员版）

> 系统就是一个网页文件（`证据采集系统.html`），用手机浏览器打开即可，不用安装。建议用手机自带浏览器或 Chrome / Safari 打开；**微信里打开可能下载不了证据包**，请点右上角"…"→"在浏览器打开"。

## 现场取证 7 步

**第一步　登录**
选自己的名字，输入 4–6 位数字 PIN。连续输错 5 次要等 30 秒。忘了 PIN 请找管理员重置。

**第二步　新建案件**
点"＋ 新建案件"→ 填案件编号（没有正式编号可先点"临时编号"，以后在"编辑信息"里改）→ 选案件类型（无证运输 / 无证经营 / 假烟销售 / 制假窝点）→ 现场地址、当事人可填可不填 →"创建并开始取证"。
新建的案件暂时没有承办人，由管理员之后分配。

**第三步　按清单逐项拍照**
页面按类别列出要拍的项目，红框、标"必拍"的必须拍，标"选拍"的看情况拍。
- 点"拍照"直接调相机；聊天记录、转账记录这类截图点"相册"选图。
- 拍完如果提示"建议重拍：画面偏暗 / 过曝 / 可能模糊"，照片已经保存了，只是提醒你看一下，需要的话点"重拍"。
- 点缩略图可看大图、拍摄时间、位置；拍错了可"重拍""相册替换"或"删除"。重拍时会先让你对比新旧两张，选"保留原照片"就不会换掉。
- 清单外还想补的照片，拍在最下面"补充照片"里，并写一句说明。

**第四步　涉案物品录入（自动带出品规和价格）**
在"涉案物品录入"下点"＋ 登记"。弹窗顶部可选物品类型：**卷烟**（默认）、**烟叶**、**烟丝**、**空管烟**、**电子烟**。

*卷烟*：
1. 在"条码"框输入**条包条码的后 6 位**（如中华（硬）输 `075015`），系统从内置的《2025年下半年湖南省卷烟品牌价格目录》自动带出**品规名称**和**建议零售价**；输入完整条码或点"扫码"也可以。记不住条码时，直接在"品规"框输入品名（如"芙蓉王"），从下拉里选。
2. 填**数量**：可直接输入，也可点 − / ＋ 或常用数量按钮（1、5、10、20、50）。单位默认"条"；按"包"登记时系统按每条 10 包自动折算成条来计价；雪茄按"支"计价，单位会自动改为"支"。
3. 下方"小计"实时显示金额，核对无误后：
   - 点 **"保存并继续"**：保存这一条，弹窗不关，光标回到条码框，接着录下一个品规（批量录入时最快）；
   - 点 **"保存"**：保存并关闭。
4. 同一品规再录一次时，系统会问是否**合并数量**，避免同一品规分成多行。
5. 目录里查不到的条码（如外省卷烟），手工填品规和单价后保存，系统会记住；下次输入同一条码后 6 位就能带出。手工填的价格在核价表中会注明"价格手工录入"。
6. 使用蓝牙/USB 扫码枪时：扫码后自动回车跳到数量，输完数量再按回车即"保存并继续"。

*其他涉案物品*：点顶部的类型按钮切换，单位和单价按下表自动带出，只需填数量（名称/规格可选填，如烟叶等级、电子烟品牌型号）：

| 类型 | 单位 | 单价 |
|---|---|---|
| 烟叶 | 公斤 | 66.14 元/公斤（管理员可在"管理 → 价格目录与核价表"修改） |
| 烟丝 | 公斤 | 烟叶单价的 1.5 倍（当前 99.21 元/公斤，随烟叶单价自动变化） |
| 空管烟 | 万支 | 468 元/万支（管理员可修改） |
| 电子烟 | 个 | 先选"烟弹"或"烟具"；管理员设置了标准价就自动带出，否则按核定价格手工填写 |

"保存并继续"会保持当前类型，连续录入同类物品很快。修改标准价只影响之后登记的物品，已登记的保持原价格。

登记完成后，列表底部显示**数量合计**和**涉案金额**，点"生成核价表（Excel）"可单独下载本案核价表。

**第五步　制作现场笔录和询问笔录**
在案件页"现场笔录与询问笔录"中点"＋ 现场笔录"或"＋ 询问笔录"（页面顶部的"笔录"按钮可直接跳到这里）。内容输入后自动保存，可以随时退出、回来接着写。
- **共同的基本信息**：开始时间自动填好，结束时点"现在"；地点默认是现场地址，点"附坐标"可附上照片里的定位坐标；点选执法人员（应不少于 2 人），执法证号自动带入（第一次使用请在"我的"里填写自己的执法证号）。
- **现场笔录**：
  1. 选当事人"在场 / 不在场"，不在场时填写见证人；
  2. 按案件类型点选现场检查要素（如无证运输：车辆类型、车牌号、驾驶人、存放位置、准运证情况；制假窝点：场所、设备、原辅材料等），选"先行登记保存"等措施；
  3. 点"生成草稿"，系统把执法人员和执法证号、检查情况、本案登记的涉案物品清单、照片数量、采取的措施写成"现场情况"正文，可直接修改；
  4. 点选或填写当事人意见。
- **询问笔录**：
  1. 选被询问人身份（当事人 / 驾驶人 / 证人 / 其他），填姓名和身份证号码，系统自动识别性别、出生日期并校验号码；
  2. 问题按案件类型的提纲自动列好，第一个问题是告知语（已带入单位、执法人员姓名和案由）；
  3. 逐题记录回答：可直接输入或用手机键盘的语音输入；点问题下面的常用回答（如"听清楚了""没有"）一键填入；"填入物品清单""填入本人信息"会自动写出本案登记的物品和被询问人的情况；
  4. 问题可以"改问题"、上移、删除，也可以"＋ 添加问题"（提纲里的其他问题或自己输入）；没有回答的问题不会写进笔录。
- **预览、生成 Word**：点"预览"可给被询问人、当事人看（可放大字号）；点"生成 Word"下载 .docx，每页页脚有签名栏和"第 X 页 共 Y 页"，打印后由相关人员签名、捺印。没填的地方留有横线，可以在打印件上手写。
- **定稿**：签字后点"定稿"，内容锁定不能再改；确需修改时"解除定稿"（会记入操作日志），改完要重新打印签字。

**第六步　校验并生成证据包**
点底部"校验并生成证据包"：
- 有必拍项没拍、没登记查获卷烟、或品规/数量没填，系统会**列出缺什么并拒绝打包**，点缺项可直接跳过去补。
- 都齐了就会下载一个 ZIP 文件，名字是"案件编号\_证据包\_日期时间.zip"。手机支持的话还可以点"发送/分享"直接发给承办人。

**第七步　移交**
把 ZIP 交给承办人。ZIP 里有：
- 按"案件编号\_类别\_项目.jpg"命名好的照片；
- `案件编号_涉案烟草专卖品核价表.xlsx`：按本局核价表模板生成，包含全部涉案物品的品种规格、数量、单价、合计、价格依据（非"条"计量的物品在备注中注明单位），打印后签字盖章即可（立案日期、案由在"编辑信息"中填写，不填则留空待手写）；
- `案件编号_现场笔录.docx`、`案件编号_询问笔录_姓名.docx`：系统中制作的笔录（未定稿的文件名带"草稿"）；
- `证据清单说明.txt`：案件信息、每张照片的拍摄时间、位置、SHA-256 摘要、涉案物品明细、笔录清单、操作日志；
- `SHA256SUMS.txt`：承办人在电脑上可用它核对照片和文件在打包后有没有被改动（方法写在清单说明第六部分）。

## 需要知道的限制
1. 账号权限只是界面上的控制，不是服务器级的安全保护，请不要把系统链接和数据发给无关人员。
2. 别人新建或修改的案件要刷新才能看到（列表页每 30 秒自动刷新，也可点"刷新"）；**两个人不要同时改同一个案件**。
3. 系统只能保证必拍项**不会漏拍**，不能保证**拍得对、拍得清**，照片内容仍需自己把关。
4. 备份要靠管理员定期在"管理 → 数据备份与还原"里手动导出，不是自动备份。
5. 笔录的格式和问题提纲是通用示例，请按本单位模板核对；系统生成的 Word 是电子文本，**必须打印后签字（捺印）**，系统没有电子签名功能。
6. 如果页面顶部出现红色"保存失败"，说明刚才的修改没存进去：先别关页面，检查手机存储空间后重新操作，并告诉管理员。

## 附：如何实测"单案证据采集与归档耗时"（供 QC 报告第六章使用）

**指标定义**：从到达现场开始取证，到证据按规定命名归档、可以移交承办人为止的总时长（分钟/案）。

1. **改进前**：从历史记录中整理同类型案件 **不少于 20 起**的耗时；如果是凭回忆估算的，每条都要注明"估算"。
2. **使用系统后**：同类型案件 **不少于 20 起**，用手机秒表计时。
3. **分段计时**（每起案件记 4 个数）：
   - ① 拍照：开始拍第一张 → 必拍项全部拍完；
   - ② 登记查获：开始登记 → 查获卷烟全部登记完；
   - ③ 整理命名：（改进前）整理、改名、归档照片的时间；（使用系统后）点"生成证据包"到下载完成；
   - ④ 移交：把证据交到承办人手上（或发出）所用时间。
4. **统计时同时给出中位数和平均值**，并写明样本量（例如"n=23"）。
5. 效率提升计算公式：ΔS = (M1 / M2 − 1) × 100%，M1 = 改进前，M2 = 改进后。

建议记录表格列：序号｜案件类型｜日期｜①拍照｜②登记查获｜③整理命名｜④移交｜合计｜是否估算｜备注。
