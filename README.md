# 涉烟案件现场证据采集系统

手机浏览器打开即可使用的单文件网页系统，用于涉烟案件现场取证：选案件类型 → 按清单逐项拍必拍/选拍证据 → 登记查获卷烟（品规+数量，可扫条码）→ 校验齐全 → 生成 ZIP 证据包。

## 文件

| 路径 | 说明 |
|---|---|
| `证据采集系统.html` | **交付的系统**（单文件，已内联 JSZip，断网可打包）。直接用手机浏览器打开 |
| `src/app.html` | 系统源码（JSZip 以占位符表示） |
| `build.js` | 构建：把 JSZip 和价格目录内联进源码，生成 `证据采集系统.html` |
| `data/price-catalog.json` | 内置价格目录（2025 年下半年湖南省卷烟、雪茄烟品牌价格目录，401 个品规），由 `scripts/parse_price_catalog.py` 从省局 PDF 生成 |
| `tests/` | Playwright 自动化测试；`tests/测试结果.md` 为最近一次运行结果 |
| `screenshots/` | 报告用截图（390×844 手机视口），`node tests/screenshots.js` 重新生成 |
| `docs/使用说明.md` | 给稽查人员的一页使用说明（含耗时实测方法） |
| `docs/待用户提供的数据与材料.md` | 报告和部署需要用户补充的材料清单 |

## 更新价格目录

省局每半年发布新目录后，任选一种方式：
- 管理员在系统"管理 → 价格目录与核价表"中导入 CSV（表头需含"条包条形码""规格名称""建议零售价""单位"）；
- 或在电脑上运行 `pip install pdfplumber && python3 scripts/parse_price_catalog.py 新目录.pdf`，再 `npm run build`，生成内置新目录的系统文件。

## 在自己电脑上使用

**只想用系统**：双击 `证据采集系统.html`，用 Chrome / Edge / Safari 打开即可，不需要安装任何东西。
直接打开文件时处于"本机存储模式"：数据只保存在这台电脑的这个浏览器里，多人共享需部署到支持共享存储的网页环境。

**想修改代码或跑测试**（Windows / macOS / Linux 均可）：

1. 安装 [Node.js](https://nodejs.org/) 18 或更高版本（LTS 版即可）。
2. 下载代码：`git clone https://github.com/lebrongods/ChenCigar.git`，然后 `cd ChenCigar`。
3. 安装依赖并下载测试用浏览器（只需一次）：

```bash
npm install
npx playwright install chromium
```

4. 常用命令：

```bash
npm run build               # 用 src/app.html 生成 证据采集系统.html（改了源码后要执行）
npm test                    # 构建 + 运行全部测试，并更新 tests/测试结果.md（约 2–3 分钟）
node tests/run-all.js p0    # 只跑某一组（core / accounts / seized / price / p0 / p1），或用例名中的关键词
node tests/screenshots.js   # 重新生成 screenshots/ 下的截图
```

修改系统时请改 `src/app.html`，不要直接改 `证据采集系统.html`（它会被构建覆盖）。

## 功能概览

- **账号与角色**：首次使用设置管理员；管理员管理用户、模板、条码库、备份，分配案件；稽查人员只看到分配给自己的案件，以及自己创建且尚未分配的案件。PIN 以 PBKDF2-SHA256（10 万次迭代、随机盐）保存，连续输错 5 次锁定 30 秒；旧版 `sha256:` 格式登录后自动升级。
- **按清单取证**：4 类默认案件模板（示例配置，管理员可改）；拍照或相册导入；照片压缩至长边 1280 px；可选水印（案件编号、项目、时间、采集人、位置）；拍照质量提示（偏暗/过曝/可能模糊，只提示不拦截）；可记录定位；重拍前新旧对比确认。
- **查获卷烟**：输入条码后 6 位（或完整条码、扫码、品名）即从价格目录带出品规和建议零售价；数量步进/常用数量按钮、实时小计；"保存并继续"连续录入；同品规自动提示合并；支持扫码枪回车流程；包/支按 10 包/条、20 支/包折算计价；目录外条码手工录入后记入本地条码库。
- **核价表**：按"涉案烟草专卖品核价表"模板生成 `.xlsx`（标题、立案信息、品种规格/数量/单价/合计/备注、合计行、价格依据、经办人与落款），打包时自动放入证据包，也可在案件页单独下载；单位名称、价格依据可由管理员设置；价格目录可导入 CSV 更新。
- **证据包**：打包前依次校验必拍项、查获卷烟、JSZip；ZIP 内含规范命名的照片、`证据清单说明.txt`（案件信息、拍摄时间、位置、SHA-256、查获明细、操作日志）和可直接 `sha256sum -c` 的 `SHA256SUMS.txt`；支持系统分享。
- **数据安全**：写入失败显示红色"保存失败"横幅；管理员可导出/导入全部数据（首次使用页也可直接从备份还原）；可重建案件索引。
- **存储**：优先使用宿主 `window.storage`（多人共享）；没有时退化为本机 IndexedDB 并明确提示"本机存储模式"。

## 已知限制

1. 角色权限为界面层控制，数据在共享存储中，不是服务器级访问控制。
2. 无实时同步：他人数据需刷新可见（列表每 30 秒自动刷新）；两人同时改同一案件时后保存者可能覆盖前者（系统已在每次保存前重新读取最新数据以降低风险）。
3. "必拍项缺失拦截"只保证不漏拍，不保证拍得对、拍得清。
4. 条码识别依赖浏览器 `BarcodeDetector`（iPhone Safari 一般不支持），不支持时手工输入。
5. 备份靠手动导出，不是自动云备份。
6. SHA-256 只用于核对证据包生成后是否被改动，不是防篡改措施。
