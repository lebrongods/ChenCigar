# 涉烟案件现场证据采集系统

手机浏览器打开即可使用的单文件网页系统，用于涉烟案件现场取证：选案件类型 → 按清单逐项拍必拍/选拍证据 → 登记查获卷烟（品规+数量，可扫条码）→ 校验齐全 → 生成 ZIP 证据包。

## 文件

| 路径 | 说明 |
|---|---|
| `证据采集系统.html` | **交付的系统**（单文件，已内联 JSZip，断网可打包）。直接用手机浏览器打开 |
| `src/app.html` | 系统源码（JSZip 以占位符表示） |
| `build.js` | 构建：把 JSZip 内联进源码，生成 `证据采集系统.html` |
| `tests/` | Playwright 自动化测试；`tests/测试结果.md` 为最近一次运行结果 |
| `screenshots/` | 报告用截图（390×844 手机视口），`node tests/screenshots.js` 重新生成 |
| `docs/使用说明.md` | 给稽查人员的一页使用说明（含耗时实测方法） |
| `docs/待用户提供的数据与材料.md` | 报告和部署需要用户补充的材料清单 |

## 构建与测试

```bash
npm install          # 安装 jszip、playwright（不需要 playwright install，使用本机 Chromium）
npm run build        # 生成 证据采集系统.html
npm test             # 构建 + 运行全部测试，并更新 tests/测试结果.md
node tests/screenshots.js   # 重新生成截图
```

## 功能概览

- **账号与角色**：首次使用设置管理员；管理员管理用户、模板、条码库、备份，分配案件；稽查人员只看到分配给自己的案件，以及自己创建且尚未分配的案件。PIN 以 PBKDF2-SHA256（10 万次迭代、随机盐）保存，连续输错 5 次锁定 30 秒；旧版 `sha256:` 格式登录后自动升级。
- **按清单取证**：4 类默认案件模板（示例配置，管理员可改）；拍照或相册导入；照片压缩至长边 1280 px；可选水印（案件编号、项目、时间、采集人、位置）；拍照质量提示（偏暗/过曝/可能模糊，只提示不拦截）；可记录定位；重拍前新旧对比确认。
- **查获卷烟**：品规+数量必填（单位 条/包/支/件）；BarcodeDetector 扫码，不支持时手工输入；GTIN 校验位检查；条码库自动学习"条码→品规"。
- **证据包**：打包前依次校验必拍项、查获卷烟、JSZip；ZIP 内含规范命名的照片、`证据清单说明.txt`（案件信息、拍摄时间、位置、SHA-256、查获明细、操作日志）和可直接 `sha256sum -c` 的 `SHA256SUMS.txt`；支持系统分享。
- **数据安全**：写入失败显示红色"保存失败"横幅；管理员可导出/导入全部数据（首次使用页也可直接从备份还原）；可重建案件索引。
- **存储**：优先使用宿主 `window.storage`（多人共享）；没有时退化为本机 IndexedDB 并明确提示"本机存储模式"。

## 已知限制

1. 角色权限为界面层控制，数据在共享存储中，不是服务器级访问控制。
2. 无实时同步：他人数据需刷新可见（列表每 30 秒自动刷新）；两人同时改同一案件时后保存者可能覆盖前者（系统已在每次保存前重新读取最新数据以降低风险）。
3. "必拍项缺失拦截"只保证不漏拍，不保证拍得对、拍得清。
4. 条码识别依赖浏览器 `BarcodeDetector`（iPhone Safari 一般不支持），不支持时手工输入。
5. 备份靠手动导出，不是自动云备份。
6. SHA-256 只用于核对证据包生成后是否被改动，不是防篡改措施。
